# AgriShield
Plant Disease Diagnosis &amp; Treatment Manager

DBMS project

Contributors - Aayush Gharat & Krishna Gajara

Functioning:

Symptom Input: The farmer enters the visible symptoms observed on the plant, such as yellowing, spots, wilting, or leaf curling.

Disease Identification: The application compares the provided symptoms with disease information stored in the database to identify the most likely disease.

Treatment Recommendations: Based on the identified disease, the application provides relevant medication and treatment advice.

Preventive Measures: The application suggests precautions and preventive practices to help control the disease and reduce the risk of future infections
